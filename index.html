فرق بسيط… بس بيغيّر طريقة تفكيرك

كتير بيحفظوا إن const بتُستخدم بدل let من غير ما يفهموا السبب. عندنا هتفهم إن اختيار الكلمة دي قرار هندسي بيوضّح نيتك في الكود قبل ما يوضّح الكود نفسه.

  • ✓ تفهم منطق القيمة الثابتة قبل ما تكتبها
  • ✓ تبني عادة برمجية سليمة من أول درس
  • ✓ تقدر تشرح قرارك مش بس تنفذه
lesson-01.js 
// Wrong way
let price = 150;

// Right way
const price = 150;
// Immutable value + clear intent = readable code

هتفهم مع إيهاب الكومي جوّه الـ JS

مش بس syntax — هتفهم إزاي JavaScript شغالة تحت الكاپوت.

Hoisting

هتفهم ليه var بتتصرف غريب، وإزاي let وconst بيشتغلوا في Temporal Dead Zone. مش سحر — ده execution context.

JIT Compilation

JavaScript مش compiler زي C++ ولا interpreter زي Python. هي JIT compiled — بتترجم لـ bytecode وتتحسن runtime. هتفهم ليه السرعة دي ممكنة.

مرونة فائقة

هتفهم ليه JS مرنة أوي: prototype chain، first-class functions، dynamic typing — كل ده بيديك قوة لو عرفت تستخدمها صح.

async-patterns.js 
// Don't write this
fetch('/api/data')
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

// Write this instead — readable, debuggable, modern
async function getData() {
  try {
    const res = await fetch('/api/data');
    const data = await res.json();
    console.log(data);
  } catch (err) {
    console.error(err);
  }
}
