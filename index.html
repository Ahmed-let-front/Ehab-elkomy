About The Engineer

Advanced JavaScript

لما تفهم اللي بيحصل تحت الـ Syntax

هنا بنبدأ نفهم JavaScript بشكل أعمق: execution context، closures، event loop، promises، modules، والـ asynchronous patterns.

01 CORE

Execution Context

افهم إزاي JavaScript بتنفذ الكود، وإيه علاقة الـ scope والـ call stack بالموضوع.

02 ASYNC

Event Loop

تعرف ليه JavaScript قادرة تتعامل مع العمليات غير المتزامنة رغم إنها single-threaded.

03 PATTERNS

Promises & Async/Await

تبني flow نظيف للـ asynchronous operations وتتعامل مع الأخطاء بشكل احترافي.

04 MODULES

Modules & Architecture

تنظم المشروع بدل ما يتحول لملف JavaScript ضخم وصعب الصيانة.
